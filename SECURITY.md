# Security and privacy

This repository contains a reference model, agent instructions and release-validation code. It is not a security product or a guarantee about a mapped system.

Do not submit secrets, private prompts, internal source code or personal data in public issues. For a flaw in this repository that requires private detail, use GitHub's private vulnerability reporting if enabled. If it is unavailable, open an issue asking for a private reporting channel without disclosing sensitive details.

A vulnerability in a mapped third-party product should be reported through that product's own disclosure process. A model placement does not imply that the project maintains the product.
