# Related work

The AI Layer Model is a practical vocabulary for locating components and responsibilities. It is complementary to architecture and threat-modeling frameworks, and is not presented as the first layered account of AI.

- **MAESTRO**, Ken Huang / Cloud Security Alliance, published February 6, 2025: a seven-layer framework for agentic AI threat modeling. [Primary publication](https://cloudsecurityalliance.org/blog/2025/02/06/agentic-ai-threat-modeling-framework-maestro).
- **Layered Attack Surface Model (LASM)**, Kexin Chu, submitted April 25, 2026: a preprint organizing agent attack surfaces and temporal threats. [Paper and revision history](https://arxiv.org/abs/2604.23338).
- **AI Agents: Architecture and Control Plane**, Cloud Security Alliance, June 22, 2026: a ten-layer agent architecture and security overlay. [Primary publication](https://cloudsecurityalliance.org/artifacts/ai-agents-architecture-and-control-plane).
- **OWASP GenAI LLM Top 10**: a risk taxonomy that can be discussed alongside architectural responsibilities. [Project](https://genai.owasp.org/llm-top-10/).

These works differ in purpose and boundaries. A mapping made with this repository is Logan Smith's working interpretation, not a mapping endorsed by CSA, OWASP or the authors of those frameworks.
